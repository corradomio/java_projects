# Shape File

## Introduction

Un '.shp' file e' un elenco di features
ogni feature e' un record di una tabella
    ci possono essere diverse tabelle
    ogni tabella ha uno 'schema'
        ogni tabella ha un elenco di colonne
            ogni colonna ha un tipo
            c'e' come minimo 'the_geom' contenente l'oggetto geometrico che la descrive
