# Felix

Scaricare il framework da: https://felix.apache.org/documentation/downloads.html 

spacchettarlo nella directory.

mandare in esecuzione con 

```
java -jar bin/felix.jar
```

Vengono caricati i bundle presenti nella directory `bundle`.
Cancellare la cache! Altrimenti non si vedono gli aggiornamenti

# MANIFEST.MF

Mettere **sempre**  `Manifest-Version: 1.0` in testa al file, altrimenti il file viene ignorato
